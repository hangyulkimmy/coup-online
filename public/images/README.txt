Drop your Coup card images here to replace the plain colored cards.

Name them exactly (lowercase, .png):
  duke.png
  assassin.png
  captain.png
  ambassador.png
  inquisitor.png   (only needed if you use Inquisitor mode)
  contessa.png

Recommended size: portrait, roughly 3:4 ratio (e.g. 300x400).
No code changes needed — the game auto-detects them. If an image is
missing, the game just shows the colored fallback card instead.
